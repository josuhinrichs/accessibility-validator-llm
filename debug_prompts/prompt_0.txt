<section class="howToFix">
<h2>How to Fix the Problem</h2>
<div class="howToFixData">
<div class="example">
<h3 class="good">Correct markup solutions</h3>
<p>
    The <code>aria-treeitem-name</code> rule has four markup patterns that pass
    test criteria:
  </p>
<pre><code class="hljs applescript">&lt;<span class="hljs-keyword">div</span> role=<span class="hljs-string">"treeitem"</span> <span class="hljs-built_in">id</span>=<span class="hljs-string">"al"</span> aria-label=<span class="hljs-string">"Name"</span>&gt;&lt;/<span class="hljs-keyword">div</span>&gt;

&lt;<span class="hljs-keyword">div</span> role=<span class="hljs-string">"treeitem"</span> <span class="hljs-built_in">id</span>=<span class="hljs-string">"alb"</span> aria-labelledby=<span class="hljs-string">"labeldiv"</span>&gt;&lt;/<span class="hljs-keyword">div</span>&gt;

&lt;<span class="hljs-keyword">div</span> role=<span class="hljs-string">"treeitem"</span> <span class="hljs-built_in">id</span>=<span class="hljs-string">"combo"</span> aria-label=<span class="hljs-string">"Aria Name"</span>&gt;Name&lt;/<span class="hljs-keyword">div</span>&gt;

&lt;<span class="hljs-keyword">div</span> role=<span class="hljs-string">"treeitem"</span> <span class="hljs-built_in">id</span>=<span class="hljs-string">"title"</span> title=<span class="hljs-string">"Title"</span>&gt;&lt;/<span class="hljs-keyword">div</span>&gt;
</code></pre>
</div>
<ol>
<li>
<p>
      Ensure that each element with <code>role="treeitem"</code> has one of the
      following characteristics:
    </p>
<ul>
<li>Inner text that is discernible to screen reader users.</li>
<li>Non-empty <code>aria-label</code> attribute.</li>
<li>
<code>aria-labelledby</code> pointing to element with text which is
        discernible to screen reader users.
      </li>
</ul>
</li>
</ol>
<div class="example">
<h3 class="bad">Incorrect markup solutions</h3>
<p>
    The <code>aria-treeitem-name</code> rule has four markup patterns that fail
    testing criteria:
  </p>
<pre><code class="hljs applescript">&lt;<span class="hljs-keyword">div</span> role=<span class="hljs-string">"treeitem"</span> <span class="hljs-built_in">id</span>=<span class="hljs-string">"empty"</span>&gt;&lt;/<span class="hljs-keyword">div</span>&gt;

&lt;<span class="hljs-keyword">div</span> role=<span class="hljs-string">"treeitem"</span> <span class="hljs-built_in">id</span>=<span class="hljs-string">"alempty"</span> <mark>aria-label=<span class="hljs-string">""</span>&gt;</mark>&lt;/<span class="hljs-keyword">div</span>&gt;

&lt;<span class="hljs-keyword">div</span> role=<span class="hljs-string">"treeitem"</span> <span class="hljs-built_in">id</span>=<span class="hljs-string">"albmissing"</span> <mark>aria-labelledby=<span class="hljs-string">"nonexistent"</span></mark>&gt;&lt;/<span class="hljs-keyword">div</span>&gt;

&lt;<span class="hljs-keyword">div</span> role=<span class="hljs-string">"treeitem"</span> <span class="hljs-built_in">id</span>=<span class="hljs-string">"albempty"</span> <mark>aria-labelledby=<span class="hljs-string">"emptydiv"</span></mark>&gt;&lt;/<span class="hljs-keyword">div</span>&gt;
&lt;<span class="hljs-keyword">div</span> <span class="hljs-built_in">id</span>=<span class="hljs-string">"emptydiv"</span>&gt;&lt;/<span class="hljs-keyword">div</span>&gt;</code></pre>
</div>
</div>
</section><section class="whyImportant">
<h2>Why it Matters</h2>
<div class="howToFixData">
<p>
  Screen reader users are not able to discern the purpose of elements with
  <code>role="treeitem"</code> that do not have an accessible name.
</p>
</div>
</section><section class="description">
<h2>Rule Description</h2>
<div class="howToFixData">
<p>
  Aria treeitem elements must have discernible text that clearly describes the
  destination, purpose, function, or action for screen reader users.
</p>
</div>
</section><section class="algorithm">
<h2>The Algorithm (in simple terms)</h2>
<div class="howToFixData">
<p>
  Checks all elements with <code>role="treeitem"</code> to ensure that they have
  a discernable, accessible name.
</p>
</div>
</section>

<section class="howToFix">
<h2>How to Fix the Problem</h2>
<div class="howToFixData">
<div class="example">
<h3 class="good">Correct markup solutions</h3>
<p>
    Table header elements (those marked with <code>&lt;th&gt;</code> or
    <code>role="rowheader"</code> or <code>role="columnheader"</code>) should
    have visible text that describes its purpose.
  </p>
<pre><code class="hljs xml"><span class="hljs-tag">&lt;<span class="hljs-name">table</span>&gt;</span><span class="hljs-tag">&lt;<span class="hljs-name">tr</span>&gt;</span><span class="hljs-tag">&lt;<span class="hljs-name">th</span>&gt;</span>Student Name<span class="hljs-tag">&lt;/<span class="hljs-name">th</span>&gt;</span><span class="hljs-tag">&lt;/<span class="hljs-name">tr</span>&gt;</span><span class="hljs-tag">&lt;/<span class="hljs-name">table</span>&gt;</span></code></pre>
</div>
<div class="example">
<h3 class="bad">Incorrect markup solutions</h3>
<pre><code class="hljs xml"><span class="hljs-tag">&lt;<span class="hljs-name">table</span>&gt;</span><span class="hljs-tag">&lt;<span class="hljs-name">tr</span>&gt;</span><mark><span class="hljs-tag">&lt;<span class="hljs-name">th</span>&gt;</span><span class="hljs-tag">&lt;/<span class="hljs-name">th</span>&gt;</span></mark><span class="hljs-tag">&lt;/<span class="hljs-name">tr</span>&gt;</span><span class="hljs-tag">&lt;/<span class="hljs-name">table</span>&gt;</span>

<span class="hljs-tag">&lt;<span class="hljs-name">table</span>&gt;</span><span class="hljs-tag">&lt;<span class="hljs-name">tr</span>&gt;</span><span class="hljs-tag">&lt;<span class="hljs-name">th</span> </span><mark><span class="hljs-tag"><span class="hljs-attr">aria-label</span>=<span class="hljs-string">"Student Name"</span></span></mark><span class="hljs-tag">&gt;</span><span class="hljs-tag">&lt;/<span class="hljs-name">th</span>&gt;</span><span class="hljs-tag">&lt;/<span class="hljs-name">tr</span>&gt;</span><span class="hljs-tag">&lt;/<span class="hljs-name">table</span>&gt;</span></code></pre>
</div>
</div>
</section><section class="whyImportant">
<h2>Why it Matters</h2>
<div class="howToFixData">
<p>
  Table header elements should have visible text that describes the purpose of
  the row or column to both sighted users and screen reader users.
</p>
</div>
</section><section class="description">
<h2>Rule Description</h2>
<div class="howToFixData">
<p>
  Table header elements should have visible text. Ensure that the table header
  can be used by screen reader users. If the element is not a header, marking it
  up with a `td` is more appropriate.
</p>
</div>
</section><section class="algorithm">
<h2>The Algorithm (in simple terms)</h2>
<div class="howToFixData">
<p>Checks all table header elements to ensure that they have a visible text.</p>
</div>
</section>

<section class="howToFix">
<h2>How to Fix the Problem</h2>
<div class="howToFixData">
<p>
  Ensure each clickable <code>&lt;area&gt;</code> within an image map has an
  <code>alt</code>, <code>aria-label</code> or
  <code>aria-labelledby</code> attribute value that describes the purpose of the
  link.
</p>
<p>
<code>&lt;img&gt;</code> elements with <code>usemap</code> attribute values
  identify image maps that use a set of <code>&lt;map&gt;</code> tags enclosing
  clickable hotspots defined by <code>area</code> attribute values. An
  additional <code>alt</code> attribute is required to define alternate text for
  each <code>area</code>:
</p>
<pre><code class="hljs xml"><span class="hljs-tag">&lt;<span class="hljs-name">img</span> <span class="hljs-attr">src</span>=<span class="hljs-string">"images/solar_system.jpg"</span> <span class="hljs-attr">alt</span>=<span class="hljs-string">"Solar System"</span> <span class="hljs-attr">width</span>=<span class="hljs-string">"472"</span> <span class="hljs-attr">height</span>=<span class="hljs-string">"800"</span> <span class="hljs-attr">usemap</span>=<span class="hljs-string">"#Map"</span>/&gt;</span>
<span class="hljs-tag">&lt;<span class="hljs-name">map</span> <span class="hljs-attr">name</span>=<span class="hljs-string">"Map"</span>&gt;</span>
    <span class="hljs-tag">&lt;<span class="hljs-name">area</span> <span class="hljs-attr">shape</span>=<span class="hljs-string">"rect"</span> <span class="hljs-attr">coords</span>=<span class="hljs-string">"115,158,276,192"</span> <span class="hljs-attr">href</span>=<span class="hljs-string">"http://en.wikipedia.org/wiki/Mercury_%28planet%29"</span> </span><mark class="highlight"><span class="hljs-tag"><span class="hljs-attr">alt</span>=<span class="hljs-string">"Mercury"</span></span></mark><span class="hljs-tag">&gt;</span>
    <span class="hljs-tag">&lt;<span class="hljs-name">area</span> <span class="hljs-attr">shape</span>=<span class="hljs-string">"rect"</span> <span class="hljs-attr">coords</span>=<span class="hljs-string">"115,193,276,234"</span> <span class="hljs-attr">href</span>=<span class="hljs-string">"http://en.wikipedia.org/wiki/Venus"</span> </span><mark class="highlight"><span class="hljs-tag"><span class="hljs-attr">alt</span>=<span class="hljs-string">"Venus"</span></span></mark><span class="hljs-tag">&gt;</span>
    <span class="hljs-comment">&lt;!-- Remaining hotspots in image map... --&gt;</span>
<span class="hljs-tag">&lt;/<span class="hljs-name">map</span>&gt;</span></code></pre>
<h3 class="bad">Bad Example</h3>
<p>
  Don't use server-side image maps that rely on mouse click coordinates. These
  maps are not keyboard accessible, and do not provide text alternatives to the
  actionable areas of the image map.
</p>
<pre><code class="hljs xml"><span class="hljs-tag">&lt;<span class="hljs-name">a</span> <span class="hljs-attr">href</span>=<span class="hljs-string">"/maps/nav.map"</span>&gt;</span><span class="hljs-tag">&lt;<span class="hljs-name">img</span> <span class="hljs-attr">src</span>=<span class="hljs-string">"/images/navbar.gif"</span> <span class="hljs-attr">ismap</span>&gt;</span><span class="hljs-tag">&lt;/<span class="hljs-name">a</span>&gt;</span></code></pre>
</div>
</section><section class="whyImportant">
<h2>Why it Matters</h2>
<div class="howToFixData">
<p>
  Screen readers have no way of translating images into words. It is important
  that all images, including image maps, have <code>alt</code> text values.
</p>
<p>
  Screen readers typically announce the filename of the image if alternative
  text is missing. Filenames do not adequately describe images and are not
  helpful to screen reader users.
</p>
</div>
</section><section class="description">
<h2>Rule Description</h2>
<div class="howToFixData">
<p>
  An image map is a single image with many clickable areas. Like all images, an
  image map must have alternate text for <em>each</em> of the different
  clickable areas, as well as for the larger image itself, since screen readers
  have no way of translating graphics into text.
</p>
</div>
</section><section class="algorithm">
<h2>The Algorithm (in simple terms)</h2>
<div class="howToFixData">
<p>Ensures <code>area</code> elements of image maps have alternate text.</p>
</div>
</section>
